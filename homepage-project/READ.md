# Homepage Project

This is a responsive homepage layout built with HTML and CSS for The Odin Project.

## Features

- Responsive layout (mobile, tablet, desktop)
- Placeholder icons and images
- Google Fonts (Playfair Display + Roboto)
- Flexbox and media queries for layout
