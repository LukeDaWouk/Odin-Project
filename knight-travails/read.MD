# Knight Travails – Early Development

This project finds the shortest path a knight can take from a start to an end position on a chessboard.

## Features

- Uses Breadth-First Search (BFS) for optimal pathfinding
- Console-based output
- No UI dependencies

## Example

=> You made it in 3 moves! Here's your path:
[0,0]
[1,2]
[2,4]
[3,3]
