# Knight Travails – Portfolio Edition

An interactive knight pathfinder on a chessboard using BFS (Breadth-First Search).

## Features
- Visual 8x8 chessboard
- User input for start/end
- Shortest path highlighted
- Modular, clean JS

## Run locally
Just open `index.html` in a browser

## Tech
- Vanilla JS Modules
- HTML/CSS (no frameworks)
- BFS for pathfinding
